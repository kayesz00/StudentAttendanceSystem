# Student Attendance System

A Windows Forms application developed in C# for managing class groups, students, and attendance records.  
This project was created for ITS203 – Object-Oriented Design and Programming at the National Academy of Professional Studies (NAPS).

## Project Description
The Student Attendance System allows teachers to:
- Create and manage class groups
- Add and remove students
- Mark attendance as Present, Absent, or Late
- Store attendance records in memory
- Navigate through multiple Windows Forms screens

The application demonstrates OOP principles including classes, encapsulation, inheritance, polymorphism, abstraction, and exception handling.

## How to Run the Application
1. Clone or download the repository:
   git clone https://github.com/kayesz00/StudentAttendanceSystem.git

2. Open the solution file in Visual Studio:
   StudentAttendanceSystem.sln

3. Ensure ".NET Desktop Development" workload is installed.

4. Press F5 or click "Start" to run the application.

## Setup Instructions
- Requires Windows and Visual Studio 2022 (or later)
- No database setup required (uses in-memory Lists)
- All forms and classes are included in the project folder
- UI can be modified through the Visual Studio Form Designer
